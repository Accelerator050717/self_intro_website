# 原角色独立肢体动画

2026-09-22，在既有 Astro 网站增量实现。原4张参考PNG仍留在本机私有素材目录；没有匹配的已绑定3D模型，因此采用保真二维分层骨架。五张优化图共99,516字节，来自现有正面WebP，未上传第三方、替换角色、重画脸或引入外部人形。

身体底图移除了挥手侧原手臂。上臂、前臂与手为独立图层，补足肩端、肘端及腕端最小遮挡区，头部独立。袖口压在手的近端补片上；裤子、鞋和另一只手属于固定身体层。素材方法与已修的接缝问题见 [REVISION-ASSETS.md](REVISION-ASSETS.md)。

`Avatar.tsx` 使用嵌套 SVG group 和浏览器 Web Animations API；body 始终无变换。肩最大 -68°、肘相对 -64°、手腕在 ±12° 内两摆，头部最多 -2°，2.6秒后全部复位。鼠标反馈只给头部 ±3°。没有持续的整图晃动，没有四视图切换或虚构眨眼。

最初集成验收发现，冰积木第一次 GPU 初始化会占用主线程并跳过手腕中间帧。现在必须先确认3D真实首帧或SVG降级，再开始会话欢迎；初始化期间招呼按钮暂不可触发，原人物保持完整可见。招呼期间展台停止动态更新。真实录屏中已完整看到两次摆腕，不能把修复前的按钮事件当作视觉完成。

## 交互与失败边界

- 当前页面人物可见、五层 decode 完成且场景准备好后，`sessionStorage` 记录本会话自动欢迎。语言切换或返回首页不重播。会话存储不可用时不自动播放，手动动作仍可用。
- 点击人物、文字按钮、键盘 Enter/Space 或触屏均触发同一实际关节动画。busy ref 同步拒绝连续点击，无无限队列；不通过 React 每帧重渲染驱动。
- 暂停沿用 `ice-paused`。暂停、离屏、页面隐藏或减少动态效果会取消动画并归零，恢复不补播。reduced-motion 保留静态角色与文字回应，鼠标也不转动头部。
- 图层加载/解码失败保持原正面图片。3D模块、WebGL或环境资源失败保留SVG，人物仍可响应。JS未运行时SSR正文和原图片可见。
- 仅清除已退休的 `mingyang:ice-play:v1`，不调用 `localStorage.clear()`。
